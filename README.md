# Restaurant Ordering & Table Reservation System

A console-based restaurant ordering and table reservation system developed in **C** as my first-semester Programming Fundamentals project.

 Features
- Food ordering with categorized menu items
- Table reservation and availability checking
- Automatic bill calculation
- Cash payment and change calculation
- Estimated food preparation time
- Password-protected manager panel
- Adding new food items to the menu
- Colored console interface

 Technologies Used
- C Programming Language
- Structures and Arrays
- Functions
- Conditional Statements
- Loops
- String Handling How to Run
1. Download or clone this repository.
2. Open `PF-PROJECT.c` in a C compiler or IDE.
3. Compile and run the program.
4. Choose the Customer Panel or Manager Panel to explore its features.

 
 Project Purpose
This project was developed to apply fundamental programming concepts to a practical restaurant ordering and billing application.
